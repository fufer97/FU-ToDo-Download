# FU ToDo · 下载

这是 **FU ToDo** 的安装包下载仓库（源码仓库是私有的，这里只放公开可下载的安装包）。

## 下载

到 [Releases](https://github.com/fufer97/FU-ToDo-Download/releases/latest) 下载最新的 `FU ToDo.dmg`：

1. 双击 `FU ToDo.dmg` 挂载
2. 把 **FU ToDo** 拖进「应用程序」
3. 首次打开请 **右键 → 打开**（应用是 ad-hoc 签名，没有 Apple 开发者证书，只需放行一次）

需要 macOS 14 或更高。

## 应用在做什么

一个给低精力人群用的 Mac 每日计划应用：**一天一件最重要的事 + 若干支线**，
写不下的自动进「未完成项目清单」，每天自动开新的一天，不结转、不堆积。

应用里的 **设置 → 更新 → 检查更新** 就是读这个仓库的 Release 版本号。
